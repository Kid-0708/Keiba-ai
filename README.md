# keiba-ai（AI競馬予想）

中央競馬・地方競馬の公式サイトから公開情報を自動で取得し、各馬の勝率・連対率、根拠、買い方別の買い目を表示する個人用の予想アプリです。

## しくみ

| 場所 | 役割 |
|---|---|
| `scraper/` | 公式サイトから出馬表・オッズ・馬体重・結果を取得（3秒以上の間隔をあけ、robots.txtを守る） |
| `pipeline/model.py` | 特徴量づくり → 学習（LightGBM）→ オッズとの統合 → 根拠（SHAP）→ 当日の馬場傾向 |
| `pipeline/export.py` | アプリ用の `docs/data.json` を出力 |
| `docs/` | アプリ本体（GitHub Pagesで公開） |
| `.github/workflows/update.yml` | 自動更新（前日18時、当日9時、10〜21時の30分ごと） |

## 費用
